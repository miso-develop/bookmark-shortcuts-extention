# Bookmark Shortcuts Minimal

Firefox のブックマークツールバーをキーボードから直接操作するための、最小権限の WebExtension です。

## ショートカット

| ショートカット | 通常ブックマーク | フォルダ |
| --- | --- | --- |
| `Alt+1` ～ `Alt+9` | 左から 1 ～ 9 番目を現在のタブで開く | フォルダ内容をポップアップで開く |
| `Alt+0` | 左から 10 番目を現在のタブで開く | フォルダ内容をポップアップで開く |
| `Alt+Shift+1` ～ `Alt+Shift+9` | 左から 1 ～ 9 番目を新しいタブで開く | フォルダ内容をポップアップで開く |
| `Alt+Shift+0` | 左から 10 番目を新しいタブで開く | フォルダ内容をポップアップで開く |

現在のタブがピン留めされている場合は、ピン留めタブを上書きせず新しいタブで開きます。

番号はブックマークツールバー上の表示順に対応します。フォルダや区切りも位置として数えます。区切りを指定した場合は何もしません。

## フォルダ対応

Firefox の WebExtensions API には、ブックマークツールバー上のネイティブなフォルダメニューそのものをプログラムから展開する API がありません。

そのため本拡張では、ブックマークツールバー上に配置した拡張ボタンから専用ポップアップを開き、対象フォルダの内容を表示します。

- ネストしたフォルダをその場で辿れます。
- フォルダ内のブックマークをクリックすると現在のタブで開きます。
- `Ctrl+クリック` では新しいタブで開きます。
- 現在のタブがピン留めされている場合は新しいタブで開きます。
- ポップアップを開けない環境では、同じフォルダビューを新しいタブで開くフォールバックがあります。

### ポップアップ内のキーボード操作

フォルダポップアップを開くと、先頭の選択可能項目が選択状態になります。

| キー | 動作 |
| --- | --- |
| `↓` | 次のブックマーク / フォルダを選択。末尾では先頭へ循環 |
| `↑` | 前のブックマーク / フォルダを選択。先頭では末尾へ循環 |
| `PageDown` | 約 1 画面分下の項目へフォーカスを移動し、表示位置も追従 |
| `PageUp` | 約 1 画面分上の項目へフォーカスを移動し、表示位置も追従 |
| `Enter` | 選択中の項目を開く。フォルダならそのフォルダへ移動 |
| `Ctrl+Enter` | 選択中のブックマークを新しいタブで開く。フォルダならそのフォルダへ移動 |
| `←` | サブフォルダから 1 階層戻る |
| `Backspace` | サブフォルダから 1 階層戻る |

`PageUp` / `PageDown` は、現在のポップアップ表示高さと項目の高さから 1 ページ相当の件数を算出します。移動先は先頭 / 末尾を越えず、その項目へフォーカスしたうえで `scrollIntoView()` します。

サブフォルダへ移動するたびにポップアップ内の履歴を保持し、`←` / `Backspace` では直前に表示していたフォルダへ戻ります。マウスで項目にカーソルを合わせた場合も、キーボードの選択位置をその項目へ同期します。

### Enter を常に新しいタブにする

ポップアップ上部の **「Enterで常に新しいタブで開く」** を有効にすると、通常の `Enter` でもブックマークを新しいタブで開きます。

- デフォルト: OFF
- 設定は拡張ページ自身の `localStorage` に保存
- `storage` WebExtension 権限は不要
- フォルダ上の `Enter` は設定に関係なく、そのフォルダへ移動

## ブックマークバー上のフィードバック

拡張ボタンは Firefox の `personaltoolbar`、つまりブックマークツールバーに配置されます。

ショートカット実行時、拡張ボタンに約 0.9 秒だけバッジを表示します。

- 通常ブックマーク: `1` ～ `10`
- フォルダ: `F1` ～ `F10`

同時にボタンのツールチップも対象ブックマーク / フォルダ名へ一時的に切り替わります。

## 権限

要求する WebExtension 権限は `bookmarks` のみです。

```json
"permissions": [
  "bookmarks"
]
```

以下の権限は要求しません。

- `tabs`
- `storage`
- `activeTab`
- `<all_urls>`
- その他の host permissions

`browser.tabs.create()` / `browser.tabs.update()` / URL やタイトルを参照しない通常の `browser.tabs.query()` は、この用途では `tabs` 権限を追加せず利用できます。

## プライバシー / セキュリティ

- Content Script なし
- Web ページ内容へのアクセスなし
- 外部通信なし
- 外部ストレージ利用なし
- 「Enterで常に新しいタブ」設定のみ拡張ページの `localStorage` にローカル保存
- npm 依存なし
- ビルド工程なし
- Firefox 向け Manifest V3
- AMO 向けに `data_collection_permissions.required = ["none"]` を明示

## 一時インストールして試す

1. このリポジトリを clone または ZIP で取得します。
2. Firefox で `about:debugging#/runtime/this-firefox` を開きます。
3. **一時的なアドオンを読み込む** を選択します。
4. このリポジトリの `manifest.json` を選択します。
5. ブックマークツールバーの先頭 10 項目にブックマークやフォルダを置き、`Alt+1` などを試します。

一時インストールした拡張は Firefox の再起動で削除されます。

## ショートカットを変更する

1. `about:addons` を開く
2. 右上の歯車メニューを開く
3. **拡張機能のショートカットキーの管理** を選択
4. 各コマンドのキーを変更する

## テスト

Node.js 22 以上で以下を実行します。

```bash
npm test
```

テストでは以下を検証します。

- 現在タブ / 新規タブでのブックマーク遷移
- `Ctrl+Enter` による新規タブ強制
- ピン留めタブ保護
- フォルダのポップアップ表示とフォールバック
- ネストしたフォルダデータ取得
- フォルダ内ブックマーク遷移
- ポップアップの `↑` / `↓` 選択と循環
- `PageUp` / `PageDown` のページ単位フォーカス移動と境界処理
- `Enter` / `Ctrl+Enter` / `←` / `Backspace` のキーマッピング
- Enter 常時新規タブ設定の判定
- ブックマークバー上のバッジフィードバック
- 1 ～ 10 番目の位置対応
- Manifest V3 / 最小権限
- `personaltoolbar` へのアクション配置
- 20 個のキーボードショートカット定義
- データ収集なし宣言

GitHub Actions でも `main` への push と Pull Request ごとに同じテストを実行します。

## 常用する場合

通常版 Firefox へ永続インストールするには Mozilla の署名が必要です。

この拡張は Manifest V3 の Add-on ID と AMO 向けデータ収集宣言を `manifest.json` に含めています。公開せずに利用する場合は AMO の **Unlisted** 配布として署名済み XPI を取得できます。
